The funniest one-line pickup line a robot could use, 200 characters or fewer - entered for the make.fun bounty "The Robot Pickup Line Championship".

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
